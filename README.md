# OpenCameraNGallery

SwiftUI Custom Media Picker – A Modular and Maintainable Solution


This repository provides a custom SwiftUI solution for selecting media (photos and videos) on iOS, overcoming the limitations introduced in iOS 17.<br> Unlike previous implementations, this approach ensures modularity, easy maintenance, and thread safety.

🚀 Features:<br>
✅ Select photos and videos from the gallery<br>
✅ Capture images using the camera<br>
✅ Limit the selection to a maximum of three files<br>
✅ Restrict video duration to 30 seconds<br>
✅ Display selected file names instead of thumbnails<br>
✅ Remove selected files before finalizing the upload<br>
