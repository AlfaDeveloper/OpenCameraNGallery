# OpenCameraNGallery
Title: 📱 SwiftUI Custom Media Picker – A Modular and Maintainable Solution


Description:
This repository provides a custom SwiftUI solution for selecting media (photos and videos) on iOS, overcoming the limitations introduced in iOS 17. Unlike previous implementations, this approach ensures modularity, easy maintenance, and thread safety.

🚀 Features:
✅ Select photos and videos from the gallery<br>
✅ Capture images using the camera
✅ Limit the selection to a maximum of three files
✅ Restrict video duration to 30 seconds
✅ Display selected file names instead of thumbnails
✅ Remove selected files before finalizing the upload
